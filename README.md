164 characters, under the 200-character limit, with no trailing newline.

> Came for the rings, stayed for the snacks. Four stars: gorgeous oceans, but the locals wave glowing rectangles at the sky and call it connection. Will abduct again.

The alien came for the rings (wrong planet), stayed for the snacks, left four
stars, and closes with a tourist's promise to return — by abduction.
